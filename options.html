Privacy

What the extension does — and what it does not do.

  • No cookies. Requests use credentials: omit; the extension does not read or send cookies.
  • No content scripts on the sites you browse. It does not read what you browse.
  • No history or tabs permissions. Optional click mode uses a temporary tab and one-off scripting.
  • No sync. Settings and words live in storage.local, not in the cloud.
  • Click mode is off by default. When enabled, it opens a temporary inactive tab, uses the normal browser profile, and clicks one organic result. It never clicks ads.
  • But: requests still go from your IP to the selected search engine. This is not anonymity; use VPN/Tor and a separate profile.
